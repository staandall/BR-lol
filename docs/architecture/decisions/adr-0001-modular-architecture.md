# Decisões técnicas

Este diretório mantém registros de decisões técnicas do projeto BR-lol. Os documentos aqui presentes devem ser lidos como propostas iniciais, não como escolhas definitivas.

## Objetivo

- registrar intenções e trade-offs;
- documentar por que uma direção foi considerada;
- facilitar a revisão e a evolução do desenho técnico.

## Convenção

Os arquivos devem seguir uma estrutura simples:

- título;
- contexto;
- proposta;
- impactos esperados;
- riscos e incertezas;
- status.

## Status atual

- Proposto: decisão sugerida, ainda sujeita a validação.
- Aceito: decisão validada pelo time.
- Rejeitado: opção descartada.
- Obsoleto: decisão que foi substituída.
